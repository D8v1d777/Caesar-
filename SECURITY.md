# Security Policy

## Reporting a vulnerability

Please do not report exploitable vulnerabilities with confidential data in public issues. Use GitHub's private vulnerability reporting feature if enabled for this repository. If it is unavailable, contact the repository owner through a verified private channel and share only the minimum information required to reproduce the issue.

Do not include real company datasets, customer records, credentials, access tokens, raw audio, or confidential transcripts in reports.

## Scope

Security reports may include authorization bypass, cross-tenant data exposure, prompt injection leading to unauthorized actions, unsafe plugin installation, secret leakage, unapproved network egress, approval replay, and data retention/deletion failures.

## Current status

Caesar is at the documentation and planning stage. No production deployment or security certification is claimed. Do not connect real company systems until the relevant implementation and security gates have been reviewed and passed.
